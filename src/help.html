Start a review

LayerProof lets you compare a PDF’s scanned page with its stored OCR text, record findings in Excel, and export corrected copies. It works locally and does not upload your documents.

  1. Choose Open review project.
  2. Select your Excel control workbook (.xlsx), then the root folder containing the PDFs. Subfolders are included.
  3. Select a document from the queue. Compare its page image with Stored OCR text.
  4. Review and check each page, choose the document’s Has issues decision, then save.

You do not need Python or Microsoft Excel installed. Close the workbook in Excel before saving from LayerProof.

Prepare the workbook

Use one control sheet with these columns. The header row may appear below a title.

ColumnContents
A — Document IDThe PDF filename, such as 40 or 40.pdf.
B and CYour existing information; LayerProof leaves it unchanged.
D — Has IssuesYes or No for the document as a whole.
E — ConcernsProblems found, including page numbers.
QC ReviewedAdded after existing columns on saving, if absent. An existing QC Performed column is also recognized.

Has Issues = Yes and QC Reviewed = Yes is valid: the document has problems, and its review is complete. Duplicate document IDs remain separate Excel rows; check the displayed row number before saving.

Review and check pages

Click a text segment or its box on the scan to highlight the corresponding content. Look for missing or incorrect words, stray characters, alignment problems, and reading order errors. Show OCR on scan is a diagnostic text overlay, not the original font rendering.

  • Quick concerns add a page-numbered note and set Has issues to Yes. Moving to another page or saving checks that page if its new concern remains in the notes.
  • No issues on this page checks the page. Remove any existing concerns for that page first. This does not choose the document-wide decision.
  • Mark page checked checks the page without changing the decision or concerns.
  • Next page → beneath the quick review buttons checks the current page and advances. The top arrows are browsing controls.
  • Use the Page checked checkbox to check or uncheck a page. On the last page, use a checking control before saving.

Use Turned page, Skewed image, Crooked page, or Bad scan to record image problems. Drag the divider to resize the scan and text panes. Focus the divider and use arrow keys to resize with the keyboard; Home resets it.

Save, exit, and resume

ButtonWhat it saves
Save to workbookThe current document’s review decision, concerns, and QC Reviewed status in Excel. Earlier saved documents are already recorded.
Save & next documentThe same review information, then opens the next unfinished document. Export pending PDF changes before moving on.
Export corrected PDFStaged text corrections, deletions, and page turns in a separate PDF. Save the review afterward to record its export note in Excel.

To finish for the day: export any pending PDF changes, save the review to the workbook, then close the app. Saving a partial review is allowed with Has issues = Yes and a concern. Saving No requires all pages checked and no concerns.

Saving with all pages checked writes QC Reviewed = Yes; partial reviews write No. Yes, TRUE, or 1 keeps completed rows out of Needs review after restarting or moving the workbook to another computer. Use Completed reviews or All workbook rows to see them again.

To return a completed document to the queue, clear QC Reviewed or set it to No in Excel, then reopen the project. Detailed page checkmarks are local to the reviewer’s computer. Sort whole Excel rows, including QC Reviewed. Use one worker per workbook copy.

Each save creates a pre-save copy in the workbook’s .backups folder. If the workbook was changed outside LayerProof, reopen it before saving; keep a copy of your unsaved notes first.

Correct or delete OCR text

  1. Select the stored text, then choose Correct OCR text….
  2. Choose the intended text block. Identical words can belong to different blocks.
  3. Edit the replacement and choose Stage correction, or choose Delete erroneous text to remove the entire selected block. For a punch hole read as a character inside a valid line, remove just that character from the replacement.
  4. Choose Export corrected PDF… and select a separate output folder.

Exports keep the original filename and include a .corrections.json change log. Keep the output folder outside the source PDF folder tree to avoid duplicate matches on rescanning. Existing output files are not replaced; choose another output folder if the name already exists.

The original PDF is unchanged. Further exports while that document stays open include prior changes. To continue editing later from the corrected version, select its folder as the PDF source.

Only supported invisible OCR text blocks can be edited. Visible text, nested text, encrypted PDFs, and signed PDFs may be review-only. Font limitations can prevent a replacement; an export is refused if verification fails. LayerProof does not create missing OCR, repair accessibility tags, or replace bad scans.

Turn a page and save it

  1. Use Rotate page left or Rotate page right in the toolbar. Each click turns the page 90 degrees.
  2. Turn any other pages that need correction.
  3. Choose Export corrected PDF…. Rotation can be exported alone or with text changes.
  4. Save the review to the workbook to record the export note.

The page image and OCR layer turn together in the saved PDF. This corrects sideways or upside-down pages; it does not straighten a slightly skewed scan. The original stays unchanged. Unexported turns are lost if you explicitly discard them.

Understand accuracy results

The optional accuracy tool compares the current page’s extracted text with a transcript you have manually verified. Enter that reference transcript, then calculate the character and word error rates. Lower rates indicate fewer differences; insertions can produce rates above 100%.

These results depend on reference quality and extraction order. They are not an automatic document quality score or an accessibility certification. The transcript is an unsaved scratchpad; put findings in Concerns. A page with no extractable text needs inspection: a blank page or an image-only map is not automatically an OCR error.

Troubleshoot and get support

  • PDF missing: open Document discovery. Check the selected root folder, scan warnings, unmatched rows, and suggested filenames. Rescan after file transfers finish. Use Change PDF folder if you selected a folder that is too narrow.
  • Combined or duplicate filenames: choose the correct PDF explicitly in PDF assignment. Suggested matches are not assigned automatically.
  • Cannot save Excel: close it in Excel, check folder permissions, and follow the error message. If another process changed it, preserve your notes and reopen the workbook.
  • Cannot export: check the destination folder and filename collision. For text changes, try a smaller correction or record the issue for another repair tool. Signed or encrypted files are not edited.
  • Document disappeared: check Completed reviews. Finished rows are hidden from Needs review.

For help, contact your project lead or the person who supplied LayerProof. Include the app version shown in this window’s title and the exact error. Document discovery can export a scan report; it contains document IDs and local paths, so review it before sharing.

To uninstall on Windows, close the app and use Settings → Apps → Installed apps → LayerProof → Uninstall. Project files outside the installation folder and local review history are retained. Keep workbooks and PDFs outside the application installation folder.
